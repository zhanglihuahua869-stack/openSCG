# 📊 项目现状分析与运行指南

## 1. 项目仓库现状分析
当前项目是一个基于 Next.js 的前端应用（包含自定义的 Socket.IO 服务），结合了 Redis 作为可能的 Pub/Sub 存储。
- **目录结构**：
  - `openscg_app/`：核心的前端与服务端代码（Next.js 15+, React 19, Socket.IO, TailwindCSS）。
  - `openscg_app/server.js`：自定义的 Next.js 启动服务器，集成了 Socket.IO，支持本地 `NO_REDIS` 模式和 Redis 模式。
  - `docker-compose.yml`：用于编排 `openscg-app` 和 `redis` 容器。
  - `start-dev.sh` / `openscg_app/dev.ps1`：提供快速启动和内网穿透（ngrok）的开发脚本。

## 3. 如何运行项目

### 方案 A：使用 Docker Compose（推荐，包含 Redis 环境）
如果您希望启动完整的生产/测试环境（带 Redis）：
1. 在项目根目录（`e:\work\survey\HeartScan-openSCG\openSCG`）打开终端。
2. 运行命令：
   ```bash
   docker-compose up -d --build
   ```
3. 访问 `http://localhost:3000`。

### 方案 B：本地原生开发模式（无 Redis）
如果您只需开发前端 UI 和基础功能，不需要启动 Redis 容器：
1. 进入应用目录：
   ```powershell
   cd openscg_app
   ```
2. 安装依赖（如果尚未安装）：
   ```powershell
   pnpm install
   ```
3. 运行安全启动脚本（会自动清理缓存并设置 `NO_REDIS=true`）：
   ```powershell
   .\dev.ps1
   ```
   或者直接运行：
   ```powershell
   $env:NO_REDIS="true"; pnpm run dev
   ```
4. 访问 `http://localhost:3000`。
